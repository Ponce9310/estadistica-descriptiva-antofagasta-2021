# Estadística Descriptiva - Antofagasta 2021

## Descripción

Trabajo de Estadística Descriptiva realizado a partir de la base de datos de matrícula de educación superior de la Región de Antofagasta correspondiente al año 2021.

El análisis se realizó utilizando Python y Google Colab, aplicando herramientas de estadística descriptiva.

## Objetivo

Analizar y describir información relacionada con la matrícula de educación superior en la Región de Antofagasta durante el año 2021, utilizando diferentes herramientas de estadística descriptiva.

## Variables analizadas

Durante el trabajo se analizaron diferentes variables de la base de datos, entre ellas:

- Género
- Tipo de institución
- Área de conocimiento
- Edad
- Valor de matrícula
- Valor de arancel
- Duración total de la carrera

## Análisis realizado

El trabajo considera:

- Frecuencia absoluta
- Frecuencia relativa porcentual
- Tablas de frecuencia
- Gráficos estadísticos
- Medidas de tendencia central
- Percentiles
- Medidas de dispersión
- Interpretación de resultados
